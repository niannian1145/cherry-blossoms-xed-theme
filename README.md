# Cherry Blossoms — Theme for Xed‑Editor

Cherry Blossoms is a custom color theme made for Xed‑Editor, inspired by soft sakura cherry‑blossom tones.
It includes both light and dark color sets, so you can work comfortably day and night.

Every part of the editor gets styled, including code syntax highlighting and the built‑in terminal.
UI details such as line highlights, pop‑up suggestions and code warning tips are all adjusted to match the theme style.

## What you get
- Separate light and dark color schemes
- Syntax highlighting for most common programming languages
- Custom color palette for the built‑in terminal
- Fine‑tuned editor elements: current‑line marking, line numbers, text selection, auto‑complete menus and error hint pop‑ups
- Supports automatic light‑dark mode switch following your device system settings

## Color style
The light theme uses soft off‑white backgrounds with gentle rose‑pink accents. It keeps text easy to read for daytime editing.
The dark theme uses deeper warm background shades paired with muted blossom‑pink highlights. It reduces eye fatigue during long‑hour night coding.

All interface elements share the same color logic. The look stays consistent whether you are writing code or using the embedded terminal.
